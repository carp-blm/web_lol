## 발견 후 수정한 문제

- Windows MIME 매핑이 `.mjs`를 text/plain으로 전달하여 Worker가 실행되지 않음: 로컬 워커를 `.js`로 변경, 개발 서버 MIME 명시. 워커 시작 실패가 초기 요청 전 발생해도 후속 요청에 오류를 전달하도록 보강.
- 모바일 상단 구단명/CR 줄바꿈: 좁은 화면 배지와 간격 조정.
- 다른 탭으로 이동할 때 이전 스크롤 위치 유지: 탭 전환 시 상단으로 복귀. 모바일 새 이벤트 시 선택 영역으로 이동하고 키보드 포커스 제공.
- 테스트 출력의 Windows cp949 인코딩 오류: 콘솔 결과 구분 기호를 ASCII로 수정.
