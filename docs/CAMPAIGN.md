# 0.4 캠페인·밴픽·전술 관전 규칙

이 게임의 공통 규칙이며 실제 LoL 패치 수치나 선수 평가를 재현하지 않는다. 모든 추첨은 저장된 시드의 RNG를 사용한다. 화면 열기/새로고침은 결과를 재추첨하지 않는다.

## 영구 성장과 경기 컨디션

성장은 선수 카드 ID별로 보관한다. 다른 연도·다른 소속 카드, 미출전 후보는 성장하지 않는다. 챔피언 숙련도는 그 경기에서 선택한 챔피언만 오른다. 원본 카드 JSON은 수정하지 않는다. 다음 시즌에도 유지한다.

- 활약 점수(0~5): `(킬 + 도움×0.8) / max(1, 사망) ×0.45 + min(1.5, 분당CS/기준)×0.6 + 아군 구조×0.15`. CS 기준은 서포터 2, 다른 포지션 7이다.
- 모든 스탯 기본 증가: `0.12 + 승리×0.10 + 활약×0.045`. 전투는 KDA 참여도, 시야는 도움/구조, 성장은 CS에 따라 각각 최대 0.20을 더한다. 라인전은 기본 증가량을 사용한다.
- 숙련 증가: `(0.50 + 승리×0.35 + 활약×0.25) × (1 + 숙련 성장 유물 합계)`.
- 영구 스탯 상한 99, 숙련 상한 100. 실제 적용된 증가량을 소수점 둘째 자리까지 표시한다. 유물·시너지·컨디션은 영구 성장치로 저장하지 않는다.
- 컨디션은 각 경기 시작 시 양 팀 각 선수에게 10/20/40/20/10%로 부진/저조/보통/좋음/절정을 판정한다. 네 스탯에 −6/−3/0/+3/+6을 적용한다. 상한 99/하한 1이며 경기 종료까지 바뀌지 않는다.

## 동일 팀 시너지

실제 출전 카드의 원소속 `team_id`가 같은 선발 선수 2/3/4/5명에게 전투·시야 +2/+4/+6/+8. 구성원 전체가 같은 연도이면 +1. 구단 표시명이 우연히 같아도 ID가 다르면 적용하지 않는다. AI에도 같은 판정이 적용되며, 해당 팀의 구성원이 아닌 선수에게는 버프가 없다. 같은 선수 중복 출전 금지는 유지된다.

## 유물

공식 이름·아이콘: [Riot Data Dragon 16.20.1 ko_KR](https://ddragon.leagueoflegends.com/cdn/16.20.1/data/ko_KR/item.json). 확인한 이름/파일명은 `data/item_snapshot.json`, 효과는 `web/progression.py`에 고정한다. 네트워크 이미지 실패 시 기존 대체 아이콘을 표시한다.

| 아이템 | CR | 효과 |
| --- | ---: | --- |
| 강철의 솔라리 펜던트 | 360 | 전원 모든 스탯 +2 |
| 슈렐리아의 군가 | 320 | 전원 시야 +3, 전술 성공률 +4%p |
| 무한의 대검 | 300 | 지정 선수 전투 +7, 라인전 +3 |
| 워모그의 갑옷 | 280 | 지정 선수 모든 스탯 +3, 음수 컨디션을 0으로 보정 |
| 라바돈의 죽음모자 | 340 | 지정 선수 선택 챔피언 숙련 +8, 숙련 성장 +25% |
| 존야의 모래시계 | 300 | 전술 성공률 +7%p |
| 증폭의 고서 | 180 | 지정 선수 선택 챔피언 숙련 +4, 숙련 성장 +15% |
| 제어 와드 | 70 | 1회 소비, 현재 전술의 성공률 +12%p |
| 분노의 영약 | 120 | 1회 소비, 다음 한 경기 전원 전투 +6 |
| 마법의 영약 | 120 | 1회 소비, 다음 한 경기 전원 숙련 +6, 숙련 성장 +30% |

영구 유물은 종류별 1개, 소비성은 종류별 3개 보관 가능. 지정 유물은 획득 시 미드에 배정되며 보유 선수 중 변경 가능하다. 후보에게 배정하면 출전 전까지 효과가 없다. 경기 도중 구매/재배정은 금지한다.

죽음모자↔존야, 분노↔마법 영약은 동시 소유 불가. 사용해 다음 경기 대기 중인 영약도 반대 영약의 소유를 막는다. 이 제한은 게임 전용 규칙이다. 상점과 이벤트 모두 동일하게 검사한다.

영약은 경기 전에 사용하며 다음 한 경기만 적용한다. 제어 와드는 전술 선택 중 사용하고 같은 선택에서 중복 사용 불가. 실제 판정 확률과 화면 확률은 동일하며 상한 98%다. 현재는 유물 매각/폐기를 지원하지 않는다.

각 경기 후 보유/배타 조건을 만족하는 후보 중 최대 3종을 제시한다. 하나 또는 100 CR을 골라야 다음 경기/시즌을 시작할 수 있다. 보상·성장은 경기별 정확히 한 번 적용된다.

## 밴픽과 타깃

UI 경기 시작은 양 팀 3밴 후 포지션 순으로 교대 5픽을 거친다. 상대 밴은 우리 선수들의 공식 숙련 상위 풀, 픽은 상대 선수의 숙련 상위 풀에서 시드로 정한다. 밴과 픽은 양 팀 전체에서 중복 불가. 부분 진행을 저장/복원하며 밴픽 중 로스터·사전 챔피언 변경을 막는다. 테스트/기존 명령 호환용 직접 `start`는 사전 드래프트로 빠른 경기를 생성한다.

탱커/전사 태그의 챔피언은 전열이다. 체력 25% 이상이고 강한 CC(1.8 이상)에 묶이지 않은 전열이 후열 접근을 막는다. 아군은 앞라인 집중/뒷라인 압박을 선택한다. 상대는 전투·숙련·현재 골드·누적 피해·원딜 보정을 합산한 최고 위협 딜러를 노린다.

전열 돌파 확률: `0.08 + 이동기×0.30 + 암살자×0.22 + 숙련×0.002 + 지역시야차×0.025 − 추가전열수×0.10`, 3~75%로 제한. 돌파 실패 시 전열만 공격 가능하고 광역 공격도 막힌 후열에 무조건 적중하지 않는다. 전열이 사망·귀환·낮은 체력·강한 CC로 방어선을 잃으면 후열이 노출된다. 정밀 거리/경로 탐색 대신 사용하는 추상화다.

## 보고서·하이라이트·POTM

양측 각각 3명 이상 참여하거나 킬이 발생하면 보고서를 만든다. 참가자 이름/챔피언, 스킬별 실제 명중 대상, HP 피해와 타깃 접근 결과를 표시한다. 단일 공격에 인원수 문구를 붙이지 않는다. 전술과 라인 킬 선택은 별도 팝업이며, 선택 결과는 실제 킬·골드·체력·시야·주도권 변화와 사냥 시작을 보여준다. 밴픽 후 시작한 경기는 보고서 확인까지 엔진 시계/RNG도 정지한다.

라인 킬 선택은 추격(3턴 실제 교전, 성공 시 선공), 미니언 확보(성공 시 +120G/주도권 +1), 시야 확보(성공 시 +2)다. 실패·회피·방어로 킬을 놓칠 수 있다. 일반 라인전에서도 자동 처치가 발생한다.

사망 없이 2/3/5/7킬부터 상승세/연속 처치/막을 수 없는/전설의 시각 강조. 사망하면 현재 연속 킬은 0으로 초기화하고 최고 기록은 보관한다. 최근 하이라이트 최대 80개, 대기 보고서 최대 12개를 유지한다.

POTM 점수는 `킬×3 + 도움×1.5 − 사망×2 + 구조×3 + 실제 HP 피해/80 + 최고 연속킬 + 승리팀 보너스4`. 양 팀 10명 중 최고 점수를 선정하며 동점은 아군 우선, 카드 ID순이다. 원본 챔피언 피해량이 아니라 이 시뮬레이션의 실제 HP 감소량을 사용한다.

## 저장 호환

신규 schema 4 / 엔진 4.0. 원본 1.0/2.0/3.0 세이브는 보존된 엔진으로 먼저 재생한다. 진행 중 경기는 당시 엔진으로 마치고 다음 경기부터 성장/새 전투 규칙을 적용한다. 기존 경기의 과거 성장을 소급하지 않는다. 밴픽, 사용한 유물, 팝업 확인, 타깃 전략도 명령으로 기록한다. 속도는 실제 시각/RNG에 관여하지 않는다.
