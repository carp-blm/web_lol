## 근거와 재생성

- [공식 Data Dragon 설명](https://developer.riotgames.com/docs/lol#data-dragon). 개별 상세 자료는 각 챔피언 source 필드에 기록한다. 예: [나르 고정 패치 자료](https://ddragon.leagueoflegends.com/cdn/16.20.1/data/ko_KR/champion/Gnar.json).
- 상세 설명 캐시 data/champion_details.json.gz와 원본 skills는 보존한다. 원본 이름과 캐시 일치, 전체 ID 수, 변형 ID 중복, 합쳐진 이름 잔존을 테스트한다.
- 아펠리오스 주문명 보완: [10.8 패치](https://www.leagueoflegends.com/ko-kr/news/game-updates/patch-10-8-notes/), [26.19 패치](https://www.leagueoflegends.com/ko-kr/news/game-updates/league-of-legends-patch-26-19-notes/).
- 카르마 강화명 보완: [13.16 패치](https://www.leagueoflegends.com/ko-kr/news/game-updates/patch-13-16-notes/), [14.12 패치](https://www.leagueoflegends.com/ko-kr/news/game-updates/patch-14-12-notes/). 확인되지 않은 W 별칭은 만들지 않고 공식 기본 이름과 만트라 상태를 함께 쓴다.
- 오프라인 재생성: python scripts/build_champions.py. 공식 재수집: python scripts/sync_ddragon.py --version 16.20.1. 새 패치는 예외 검토가 끝나기 전 자동 교체하지 않는다. --allow-stale은 검증된 기존 스냅샷을 유지한다.
- 결과 revision은 구성과 변형 스킬 전체의 해시를 포함한다. 스킬 규칙이 바뀐 세이브를 조용히 다른 결과로 재생하지 않는다.

## 구현의 범위

형태·이름·태그·사용 조건을 구분하는 게임용 모델이다. 실제 LoL의 쿨다운·마나·체력·적중 판정·초 단위 전투를 그대로 재현하지 않는다. 재시전은 첫 시전 후 90초의 추상화된 창에서 가능하며, 첫 시전의 실제 적중 판정을 별도로 모델링하지 않는다. 형태 전환 시간, 분노, 야성, 별가루, 스칼 체력, 무기 탄약도 이 게임의 공통 턴 규칙을 사용한다.

니달리/엘리스/제이스/렉사이의 태세와 일부 궁극기 변신은 자동 전환한다. 전환 자체의 직접 피해·군중제어는 별도 전투 기술로 계산하지 않는다. 복사는 원본의 현재 형태 상태를 최대 90초 빌리는 모델이다. 빌린 기본기의 시전 후 형태 변경, 강화/원소 소비, 재시전은 반영하지만 원본의 수동적 자원 증가와 시간에 따른 변신은 빙의 중 독립 재현하지 않는다. 사일러스가 빌리는 변신 R의 특례는 니달리/엘리스/제이스에 적용하고, 나머지 전환 전용 R은 원래 이름을 유지한 보호 효과로 추상화한다.

이름이 그대로인 수치 강화·진화(카직스/카이사/빅토르 등), 일반 버프(아트록스/벨베스/나서스/레넥톤/판테온/애니/세라핀 등), 위장만 바뀌는 니코, 같은 이름의 반복 시전/대상 차이는 독립 공식 스킬로 새 이름을 만들지 않는다. 이들의 모든 내부 스택과 상호작용까지 구현했다는 의미는 아니다. 제외 범주는 생성 JSON의 variant_audit.excluded_categories에 기록한다.

아이콘은 공식 Data Dragon 기본 슬롯 아이콘을 공유한다. 별도 형태 아이콘을 검증해 확보한 것으로 표시하지 않으며 모든 변형의 icon_status는 base-slot-icon이다. 이미지 로드 실패 시 로컬 대체 아이콘을 사용한다.
