# 0.6 감독 운영 · 2026-11-06

신규 경기는 엔진 6.0 / 저장 schema 6을 사용한다. 전장 시뮬레이션(이동·교전·스킬·오브젝트)은 0.5와 같고, 그 위에 **경기 사이의 감독 결정**을 추가했다. 목표는 "다음 경기 전에 무엇을 할지"가 매주 달라지는 매니지먼트 루프다. 모든 추첨은 저장된 시드 RNG를 사용하며 화면 열기/새로고침은 결과를 바꾸지 않는다. 실제 구단·스폰서·패치를 묘사하지 않는 게임 전용 규칙이다. 규칙 코드는 `web/management.py`.

## 주간 루프

우리 팀 경기 1회 = 1주. 경기를 마치면(정산 시 정확히 한 번) 다음이 차례로 적용된다.

1. 경기 결과에 따라 사기(−3~+3)와 연승/연패 갱신
2. 선발 5명: 출전 피로, 주간 훈련, 주간 회복 +5 적용 → 훈련 성장 기록
3. 벤치 선수: 체력 +25
4. 스폰서 경기 수입 지급

화면: **운영 센터**(새 메뉴), 클럽 하우스의 "이번 주 운영" 띠, 경기 결과의 "이번 주 훈련 결과".

## 체력·컨디션·사기

| 항목 | 값 |
| --- | --- |
| 시작 / 시즌 시작 시 | 100 (휴식기 전원 회복, 사기는 유지) |
| 경기 출전 피로 | 8 × 피로 배율 |
| 주간 자연 회복 | +5 |
| 탈진 | 체력 25 미만: 해당 경기 모든 능력치 −4 |
| 훈련 효율 저하 | 훈련 시작 시 체력 30 미만이면 훈련 효과 50% |

컨디션 판정(0.4의 10/20/40/20/10% 1회 추첨)에 보정값을 더한다. 추첨 횟수는 그대로다.

`보정 = round((체력 − 60) / 4) + 사기 × 2 + 베테랑 8`

예: 체력 100·사기 0 → +10(좋음/절정 확률 증가), 체력 20 → −10. 결과는 1~100으로 제한한다. 사기는 승리 시 `max(0, 사기)+1`(상한 3), 패배 시 `min(0, 사기)−1`(하한 −3).

## 주간 훈련

포지션마다 하나를 지정하며 경기 중에도 다음 주 계획을 바꿀 수 있다. 미지정은 라인전 훈련.

| 훈련 | 효과 | 피로 |
| --- | --- | ---: |
| 라인전 / 교전 / 시야·운영 / 성장 | 해당 능력치 +0.45 × 효율 | 9 / 10 / 6 / 8 |
| 챔피언 연습 | 지정 챔피언 숙련 +1.6 × 효율 | 7 |
| 휴식 | 없음 | −30 (회복) |

효율 = `(1 + 원석 0.5 + 아카데미 스폰서 0.4) × (체력 30 미만이면 0.5)`, 챔피언 연습은 챔피언 폭 특성 +60%. 피로 배율 = `1 − 철인 0.4 − 웰니스 스폰서 0.2`(휴식 회복량에는 적용하지 않음). 성장치는 0.4의 경기 성장과 같은 카드별 영구 성장 기록에 합산되며 상한 99/100을 지킨다(0.7부터 능력치 상한은 선수별 커리어 고점, [CAREER_V7.md](CAREER_V7.md)). 기본 훈련만 반복하면 약 8주 후 체력이 바닥나므로 시즌 중 휴식 배분이 필요하다.

## 선수 특성

카드마다 결정적으로 1~2개. 원본 카드 데이터를 바꾸지 않으며 AI 선수에게도 같은 규칙을 적용한다.

- 대표 특성: 2군 리그 카드 또는 OVR 64 미만은 **원석**(훈련·경기 성장 +50%). 그 외에는 가장 높은 능력치에 따라 **라인 지배자**(라인전 +3) / **한타 장인**(전투 +3) / **시야 설계자**(시야 +3, 전술 성공률 +1%p) / **성장 괴물**(성장 +3).
- 보조 특성(카드 ID 해시로 80%): 출전 60회 이상 **베테랑**(컨디션 판정 +8), 승률 65% 이상 **승부사**(플레이오프 모든 능력치 +3), 3경기 이상 챔피언 6개 이상 **챔피언 폭**(연습 효율 +60%), 그리고 **철인**(피로 −40%), **강심장**(컨디션 최저 '저조').

## 경기 전략과 상성

경기 전에 팀 전략 하나를 고른다(경기 중 변경 불가). AI 구단은 시즌마다 고유 스타일을 가지며 스카우팅 리포트로 공개된다.

| 전략 | 보정 | 이기는 상대 |
| --- | --- | --- |
| 균형 운영 | 없음 | 없음(지지도 않음) |
| 난전 지향 | 전투 +3, 시야 −2 | 후반 지향 |
| 후반 지향 | 성장 +3, 라인전 −2 | 시야 장악 |
| 시야 장악 | 시야 +3, 전투 −1 | 라인 압박 |
| 라인 압박 | 라인전 +3, 성장 −1 | 난전 지향 |

상성에서 이기는 팀은 전원 모든 능력치 +2. AI끼리의 경기에도 같은 규칙을 쓴다.

## 스카우팅 리포트

다음 상대의 스타일, 평균 OVR, 전적, 선수별 특성과 (패치 반영) 주력 챔피언 3개, 상대가 노릴 가능성이 큰 우리 챔피언, 추천 전략을 보여준다. 표시 전용이며 RNG를 쓰지 않는다.

## 시즌 패치 메타

시즌 시작 시 패치 하나: 상향 4(그중 2개는 우리 선발의 주력 풀), 하향 3(그중 1개는 우리 풀), 메타 계열 1개.

- 상향: 전투 +3, 라인전 +2 / 하향: 전투 −3, 라인전 −2 / 메타 계열 태그: 전투 +2
- 양 팀 모두 적용. AI 밴픽은 `숙련 + 메타 가치(상향 +8, 하향 −8, 계열 +3)`로 점수를 매겨 상위권에서 고른다. 상향 챔피언은 숙련 35로 픽 후보에 추가된다.
- 드래프트 룸 챔피언에 ▲/▼/◆ 배지를 표시한다.

## 스폰서

시즌마다 6종 중 3개를 제안받고 하나와 계약(시즌 1회, 계약 이후부터 적용).

| 스폰서 | 조건 |
| --- | --- |
| 네온 펄스 에너지 | 승리당 +70 CR |
| 하이퍼 기어 | 경기당 +45 CR |
| 오로라 캐피털 | 결승 진출 +350 CR, 우승 +900 CR |
| 스트림박스 | 우리 팀 처치당 +6 CR |
| 퓨처랩 아카데미 | 훈련 효과 +40% |
| 그린필드 웰니스 | 주간 체력 +10, 피로 −20% |

## 리그 승강제

챌린저스 → 프로 → 마스터즈 → 월드 아레나. 리그마다 AI 구단 이름과 강도, 보상 배율이 다르다.

| 리그 | AI 목표 OVR (2~6번 구단) | 보상 배율 |
| --- | --- | ---: |
| 챌린저스 리그 | 61.8 ~ 67.0 | ×1.0 |
| 프로 리그 | 67.9 ~ 73.5 | ×1.25 |
| 마스터즈 | 72.9 ~ 78.5 | ×1.5 |
| 월드 아레나 | 78.2 ~ 83.0 | ×2.0 |

경기 보상(240/140)과 플레이오프·결승·우승 보너스(200/300/600)에 배율을 곱한다. 시즌 종료 시 **결승 진출(우승·준우승) → 승격**, **정규시즌 6위 → 강등**(최하위 리그 제외), 그 외 잔류. 최상위 리그에서는 승격 대신 우승 트로피를 쌓는다. 시작 팀으로 측정한 승률(전략·유물·성장 없음, 첫 선택지 고정, 6시드 × 5경기)은 리그 순으로 약 57% / 43% / 30% / 27%였다(표본이 작아 오차가 크다).

## 관전 템포

- 배속 1×/3×/6×/12×/30×/60×. 경기 시계는 1초마다 진행한다.
- **AI 코치**: 켜면 전술 선택은 표시 확률이 가장 높은 안을, 교전 보고서는 자동 확인한다(0.2초 간격). 모든 선택은 일반 선택과 같은 명령으로 저장된다. 60× + AI 코치에서 60분 경기는 실제 약 2분.

## 저장 호환

schema 6 / 엔진 6.0.0. 5.0 세이브는 `legacy_engine_v5.py`(동결된 5.0 엔진)로 먼저 재생한 뒤 이전한다. 이때 현재 시즌에 AI 스타일·패치·스폰서 제안을 결정적으로 추가하고(가져올 때마다 같은 결과), 진행 중 경기는 5.0 규칙으로 마치며 주간 훈련은 다음 경기부터 적용한다. 1~4세대 세이브도 같은 경로로 이전한다. 새 명령: `set_training`, `set_plan`, `sign_sponsor`.

## 의도적으로 하지 않은 것

선수 연봉·계약 기간·이적 시장, 부상, 나이/은퇴, 시즌 중 패치, 시리즈 피어리스는 이번 범위가 아니다. 후보로 [제안 목록](#다음-제안)을 남긴다.
