# 0.5 전술 전장 · 2026-10-27

신규 경기는 엔진 5.0 / 저장 schema 5를 사용한다. 이전 경기와 밴픽은 보존된 당시 규칙으로 완료하며, 다음 경기부터 새 규칙을 적용한다. 실제 LoL의 모든 규칙을 재현하는 엔진이 아니라 프로 선수 기록을 사용하는 감독 시뮬레이션이다.

## 이동과 사건

10명 모두 기지에서 출발한다. 탑·미드·바텀은 담당 라인, 서포터는 바텀, 정글은 캠프로 이동한다. 지도 좌표는 0~100이며 실제 LoL 월드 좌표가 아니다. 초당 이동, 경유점, 목적지, 합류 시간, 귀환과 부활을 유지한다. 미니맵은 같은 좌표를 사용한다.

근처 적을 5초마다 탐색하고 18거리 안의 접촉에서 교전을 만든다. 교전 중심 22거리 안의 살아 있는 선수만 참가한다. 로밍·갱·집결은 이동 명령이며 원격 참가를 허용하지 않는다. 라인 미니언, 캠프, 와드, 오브젝트도 위치를 검사한다. 사망·귀환 중에는 참가하지 못하며 기지에서 회복한 뒤 다시 걸어간다.

드래곤·전령·바론 근처에서 사냥을 시작하고, 도착한 상대가 있으면 경합한다. 바론은 최소 3명이 필요하다. 14분 이후 팀 집결이 주기적으로 발생한다. 사건은 현재 거리, 주변 인원, 체력, 시야, 오브젝트 상태를 바탕으로 구성한다. 중요 교전 보고서와 전술 선택에서는 경기 시계와 RNG가 멈춘다.

최초 처치는 추가 100G, 3연속 처치부터 처치 차단 보너스 100~400G를 지급한다. 기존 연속 처치, 하이라이트, POTM, 선수 성장, 유물 시스템과 함께 작동한다.

## 대회식 밴픽

A=우리 팀, B=상대 팀. 이번 게임은 우리 팀이 선픽하는 단일 경기 규칙이다.

| 단계 | 순서 | 각 팀 결과 |
| --- | --- | --- |
| 1차 밴 | A B A B A B | 3밴 |
| 1차 픽 | A B B A A B | 3픽 |
| 2차 밴 | B A B A | 2밴 추가 |
| 2차 픽 | B A A B | 2픽 추가 |

총 10밴·10픽, 양 팀 전체에서 챔피언 중복 금지. 픽할 포지션은 미선택 포지션 중 자유롭게 고른다. 각 입력과 AI 대응은 중간 저장/재생된다. 시리즈 피어리스 밴, 진영/선픽권 별도 선택, 선수 간 픽 교환은 이번 범위에 포함하지 않는다.

규칙 참고: [2024 공식 대회 규정의 4단계 드래프트](https://www.a-esc.com/site_data/file/regulation/2024/03/1709876317_umJZUQze_28LoL29202.pdf). 2026 대회의 First Selection 제도는 진영과 선픽권을 분리한다([Riot 시즌 안내](https://lolesports.com/en-US/lolesports/news/season-start-2026-lol-esports)). 이 게임의 선픽 고정과 구분한다.

## 소환사 주문

경기 전 클럽 하우스에서 포지션별 2개를 선택한다. 중복 주문은 불가하며 정글은 강타 필수, 다른 포지션은 강타를 사용할 수 없다. 상대도 기본 세트를 가진다.

| 주문 | 기본 대기시간(경기 초) |
| --- | ---: |
| 점멸 | 300 |
| 순간이동 | 300 |
| 점화 | 180 |
| 회복 | 240 |
| 방어막 | 180 |
| 정화 | 240 |
| 탈진 | 240 |
| 유체화 | 240 |
| 강타 | 2충전, 순차 90초 재충전, 사용 간격 15초 |

이름·아이콘·기본 시간은 [Riot Data Dragon 16.20.1](https://ddragon.leagueoflegends.com/cdn/16.20.1/data/ko_KR/summoner.json)에 고정한다. 순간이동은 10분부터 레벨에 따라 330~240초의 해방된 순간이동 시간을 사용한다([Riot 25.S1.1 패치](https://www.leagueoflegends.com/en-ph/news/game-updates/patch-25-s1-1-notes/)). 레벨은 경기 시간과 CS로 추정하며 소환사 주문 가속·룬·포지션 퀘스트의 추가 재사용 보정은 모델링하지 않는다.

위기 상황에서는 방어 주문/정화, 오브젝트 마무리에서는 강타를 자동 사용한다. 전술 팝업에서는 가능한 주변 선수의 주문 하나를 선택해 기본 성공률에 24~32%p를 추가한다(상한 98%). 화면에 최종 확률과 사용할 선수·주문·대기시간을 표시한다. 선택 확정 시에만 소모한다. 순간이동은 먼 선수의 실제 좌표를 사건 위치로 옮긴다. 일시정지·선택 대기 중에는 재충전되지 않는다. 주문 피해와 방어량은 이 게임의 HP 규모에 맞춘 값이다.

## 콤보와 관전

최대 4단계의 콤보를 사용하며 매 시전 후 형태, 재시전, 적중, CC, 쿨다운과 생존 대상을 다시 검사한다. 아리·리 신·레오나·노틸러스·알리스타·자르반·럭스·레넥톤·신드라·오리아나·야스오·리븐·엘리스·니달리는 명시적인 연계 우선순위를 가진다. 나머지는 제어·기동·피해 효과를 기준으로 연계한다. 173종에 동일한 완성도의 수동 콤보를 작성했다는 의미는 아니다.

표식이 필요한 리 신 Q/아칼리 E/벡스 R은 첫 타가 빗나가면 후속 시전을 열지 않는다. 야스오 R은 실제 공중에 뜬 대상만 공격한다. 형태/재시전 규칙은 기존 검토된 스킬 데이터를 사용한다. 정밀 투사체·장애물·공/깃발/구체의 개별 월드 오브젝트는 추상화한다.

라이브 아레나는 양 팀 로스터, 체력·KDA·CS·골드·주문 쿨다운, 오브젝트 타이머와 중앙 전장을 함께 보여준다. 지도 초상화는 실제 위치를 따라 움직이고 최근 8초의 스킬·주문 아이콘을 머리 위에 표시한다. 초상화를 누르면 최근 콤보와 가까운 적 거리를 확인한다. 단일 공격에는 적중 인원수를 붙이지 않고, 광역으로 실제 여러 명을 맞힌 경우만 인원수를 표시한다.

메뉴는 클럽 하우스 / 드래프트 룸 / 라이브 아레나 / 선수 아카이브 / 전술 연구실 / 시즌 여정 / 기록 & 출처로 구성한다. 좁은 화면에서는 지도와 팀 패널을 재배치하며, 모션 감소 설정에서는 이동·장식 애니메이션을 줄인다.
