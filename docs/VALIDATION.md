## 발견 후 수정한 문제

- Windows MIME 매핑이 `.mjs`를 text/plain으로 전달하여 Worker가 실행되지 않음: 로컬 워커를 `.js`로 변경, 개발 서버 MIME 명시. 워커 시작 실패가 초기 요청 전 발생해도 후속 요청에 오류를 전달하도록 보강.
- 모바일 상단 구단명/CR 줄바꿈: 좁은 화면 배지와 간격 조정.
- 다른 탭으로 이동할 때 이전 스크롤 위치 유지: 탭 전환 시 상단으로 복귀. 모바일 새 이벤트 시 선택 영역으로 이동하고 키보드 포커스 제공.
- 테스트 출력의 Windows cp949 인코딩 오류: 콘솔 결과 구분 기호를 ASCII로 수정.

## 아직 검증하지 않은 범위

- 실제 공개 Pages URL: 공개 이용권한 미확인으로 배포 스위치를 켜지 않았습니다. GitHub CI 실행 내역은 [Actions](https://github.com/carp-blm/web_lol/actions)에서 확인할 수 있습니다. 아래 로컬 검증은 저장소 연결 이전에 수행한 기록입니다.
- Oracle's Elixir 원본과 공개 보존본의 완전한 바이트 일치, 데이터 재배포 권한, 공식 유니폼 사진/로고 사용 허락.
- Safari/Firefox, iOS WebView, 장기 세이브 12,000개 행동 한계까지의 실기기 성능.
- 네트워크가 없는 첫 실행. Pyodide 런타임 최초 다운로드에는 네트워크가 필요함.
- 실제 LoL 경기와 동일한 밸런스/승률 예측 정확도. 이번 엔진은 게임용 추상화임.
