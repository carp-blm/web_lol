# 지속 전장 엔진 0.3

## 자동 진행과 전술 선택

기본 속도는 실제 1초당 경기 1초입니다. 3/6/12/30배속과 일시정지, 1초 진행을 제공합니다. 브라우저 탭이 백그라운드에 있거나 기기가 느리면 벽시계보다 느릴 수 있습니다. 실제 시각은 난수와 결과에 쓰지 않습니다.

라인 교전, 회피, 처치, 낮은 체력에서 귀환, 정글링, 로밍, 시야 확보는 자동입니다. 첫 전술 선택은 4분, 이후 선택 간격은 시드에 따라 210~330초입니다. 선택 대기 중에는 시간·체력·쿨다운·난수가 모두 정지합니다. 선택 확률은 **전술 실행/선공 성공률**이며, 처치 확률이나 경기 승률을 보장하지 않습니다. 선택 후 교전은 동일한 체력·적중·방어 규칙으로 따로 처리합니다.

킬은 개인 골드·KDA·팀 골드·복귀 시간에 영향을 줍니다. 귀환과 사망 중에는 라인 구성에서 빠져 미니언 수급과 포탑 방어를 포기합니다. 현재 체력·개인 성장·라인 주도권·시야가 후속 적중, 교전 우세와 선택 확률에 이어집니다. 포탑 → 억제기 → 넥서스 순으로만 피해를 줄 수 있습니다. 종료 시각이나 승자는 미리 정하지 않습니다.

## 위치와 시간

| 상황 | 공통 MVP 규칙 |
|---|---|
| 초반 인베이드 | 45초에 35%의 시드 판정, 정글·미드·서포터 참여 |
| 첫 미니언 성장 / 정글 캠프 | 90초, 이후 미니언 30초 간격 |
| 일반 라인 교전 | 95초부터 17~29초 간격에 한 라인 선정 |
| 정글 행동 | 120초부터 24~38초 간격, 갱·침입·맞대결·사냥 |
| 캠프 재생성 | 처치 후 120초; 상대가 훔치면 원래 주인도 기다림 |
| 서포터 로밍 | 180초 이후, 42~66초 동안 탑/미드로 이동 |
| 귀환 | 체력 27% 미만에서 83% 확률; 24~36초 후 복귀 |
| 사망 | 경기 시간에 따라 길어지는 부활+복귀 시간 |
| 드래곤 | 5분 출현, 처치 후 5분 |
| 전령 | 8~20분에 한 번 |
| 바론 | 20분 출현, 처치 후 6분; 강화 3분 |
| 오브젝트 사냥 | 정글 단독 28초 / 팀 18초; 발각 시 견제 교전 |

정글 단독 바론은 허용하지 않습니다. 오브젝트를 시작해도 참여자가 사망·귀환하면 실패할 수 있습니다. 와드에 발견되면 상대 합류로 사냥이 교전으로 바뀝니다. 후반에는 강가 시야 격차가 기습과 은밀한 오브젝트 사냥에 영향을 줍니다.

바텀은 원딜과 서포터가 함께 있을 때 2대2입니다. 한쪽 서포터가 떠나면 1대2, 양쪽 모두 떠나면 1대1입니다. 갱킹과 로밍 합류자는 해당 교전에 추가됩니다. 서포터만 남은 맞대결은 후보 상황에서도 0.5%만 실제 교전으로 이어집니다.

## 실측 시야

`scripts/build_vision.py`는 기존 출전 필터와 동일하게 원본 CSV의 `wardsplaced`, `wardskilled`, `controlwardsbought`를 집계합니다. 카드 ID별 총량·측정 경기 수·분당 수치와 원본 해시를 `data/seed/vision.json`에 남깁니다. 0은 실제 0으로 유지하며 누락값은 null입니다. 누락일 때만 기존 시야 능력치를 이용한 보수적 기본 확률을 사용합니다.

30초마다 와드 설치·제거·제어 와드 행동을 판정합니다. 위치별 시야는 0~10이며 시간이 지나면 감소합니다. 정글·서포터의 와드는 강가에도 영향을 줍니다. 제어 와드는 실제 경기 골드 75를 소비합니다. 시야는 갱 탐지, 역갱 합류, 적중·회피, 후반 기습과 오브젝트 발각에 쓰입니다. 실제 선수의 현재 실력을 뜻하는 수치가 아닙니다.

## 스킬 효과

고정 패치 16.20.1의 한국어 설명/tooltip/status 표시를 읽고, `scripts/skill_effects.py`의 적용 대상·형태별 예외 목록으로 보완합니다. 원본 자료는 `data/champion_details.json.gz`에 보존합니다. 불확실한 방어 대상에는 아군 보호 기능을 임의로 부여하지 않습니다. 원본 HTML은 화면에 삽입하거나 실행하지 않습니다.

| CC | 기본 강도 |
|---|---:|
| 실명 | 0.6 |
| 감속 | 1.0 |
| 속박 | 1.8 |
| 변이 | 2.3 |
| 기절 | 2.5 |
| 공중에 뜸 / 제압 | 3.3 |

실명은 원거리 기본 공격 중심 챔피언에게 2.7배의 영향을 줍니다. 침묵·공포·매혹·도발도 별도로 분류합니다. CC에 맞으면 일정 시간 동안 후속 공격을 피하기 어려워지고 전투 기여가 감소합니다. 강한 CC로 전술을 시도할 때 선공의 가치와 실패 후 반격 위험이 커집니다.

광역기는 참여한 적 각각에 대해 독립 적중 판정을 합니다. 숙련도 차이, 전투 능력치, 시야, 상대 이동기/현재 CC가 적중률에 영향을 줍니다. 명중 인원이 중계에 표시되고, 실제 맞은 대상에만 CC와 피해를 적용합니다. 럭스 Q·바드 Q는 최대 2명, 애쉬 R·레오나 R은 중심 대상과 주변 CC를 구분합니다. 첫 대상에 멈추는 주요 투사체는 광역에서 제외합니다.

회복·보호막은 자신/다른 아군/자신 또는 아군/주변 아군을 구분합니다. 소라카 W는 자신을 회복하지 못하고 체력을 소비하며, 니달리는 인간 E만 아군을 회복합니다. 리븐 E 같은 자기 보호막은 다른 선수를 구하지 못합니다. 모르가나 E는 마법 피해에만 방어 판정을 합니다. 룰루 R의 추가 체력은 일반 회복과 구분합니다. 해당 교전에 참여하고 살아 있는 보호자만 개입하며, 쿨다운과 강한 CC의 방해를 적용합니다.

치명상 시에는 일반 보호보다 낮은 확률(숙련 35~95 기준 약 6.7~13.9%)로 구조를 시도합니다. 회복/보호막이 피해를 충분히 막았을 때만 생존하며, 적절한 무적·구조·조건부 부활은 별도 처리합니다. 구조한 선수의 횟수와 중계가 남습니다.

이는 **확률적 전투 추상화**입니다. 실제 패치의 정확한 피해 공식·마나·거리·아이템·미니언별 체력·경험치 레벨·스킬별 모든 발동 조건을 구현한 것은 아닙니다. 연속 적중/벽 충돌 등 조건부 CC는 해당 스킬의 확률적 교전 판정에 포함되며, 질리언/레나타/킨드레드 등의 부활·불사 세부 시간과 조건은 공통 구조 사건으로 단순화했습니다. 예외 목록과 테스트를 추가해 확장할 수 있습니다.

## 저장과 재현

엔진 3.0.0은 시드와 명령, 카드·챔피언·효과·시야 버전을 기록합니다. 연속 시간 진행은 최대 3,600초 단위로 묶어 느린 경기에서도 세이브가 불필요하게 커지지 않습니다. JSON 4MB, 12,000명령, 재생 300,000초 상한을 검사합니다. 체크섬은 손상 감지용이며 치트 방지나 인증 서명이 아닙니다.

1.0/2.0 세이브는 해당 구버전 엔진으로 먼저 재생합니다. 보유 선수·재화·시즌과 개봉 중인 팩을 보존하고, 진행 중 경기는 이전 규칙으로 마칩니다. 다음 경기부터 새 전장을 사용합니다. 구버전 모듈은 호환성을 위해 배포 번들에 포함합니다.
